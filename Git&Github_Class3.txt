// Stash in Git & Github
* git stash
-> save all unstaged file
* git stash list
-> show all stash history
* git stash pop
-> return original interface 
* git stash apply
-> Switch last stash but don't delete history
* git stash clear
-> delete all stash
* git stash drop stash@{0}
-> delete spacific stash


// Very important Conseft

*** git cherry-pic <commit-hash>
-> merge spacific branch spacific file with <commit-hash>

// reset (soft,mixed,hard)
* git reset --soft head~1
-> delete spacific commit history but file was staged.
* git reset --mixed head~1
-> delete spacific commit history and file was unstaged.
* git reset --hard head~1
-> delete Everything.

//revert 
* git revert <git-hash>
-> most usable Conseft for solve problem in git & github .
